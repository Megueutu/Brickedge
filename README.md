# Brickade

An egress firewall written in Rust, built as a study project to learn Rust and networking.

Brickade is a local proxy that sits between your programs and the internet, decides which destinations are allowed and, in later versions, blocks requests that leak secrets such as API keys and tokens.

It is a learning project, not a security product. The idea, approach and roadmap live in [learning/](learning/) (in portuguese).
